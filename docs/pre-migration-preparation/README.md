# WorkBuddyManager

Windows WorkBuddy 多账号管理工具，准备按用户指定的 ChatGPT 对话中的执行方案实施。

## 已确认的需求

- 多账号管理与一键切换，不要求多账号并行运行。
- 每日自动签到。
- 切换账号后保留或共享会话；接受手动点击复制或增量同步。
- 以原对话指定的两个开源项目作为研究基础，合并所需功能。
