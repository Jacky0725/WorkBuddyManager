# 使用说明

当前功能状态以 [最终验收表](31-final-acceptance-checklist-2026-10-20.md) 为准。前半部分保留 alpha.1 的历史说明；当前聊天计划使用下文步骤及 alpha.11 补充。

0.2.0-alpha.1 是本地实验候选。账号管理与统计沿用 Switch 主体，每日计划、加密备份与日志统一在同一桌面进程中。

## 账号

账号管理提供添加、区域分类、备注、删除确认与重新授权入口。普通导出只含公开资料，不能恢复登录。国内/国际账号分开识别，相同 UID 不应合并成跨区域身份。凭证读取失败提示重新授权，不用空 token 静默替换有效记录。

真实登录和 A→B→C→A 切换尚未验收；切换会关闭/启动对应官方客户端，执行前应保存正在进行的工作。未完成或损坏的会话操作记录会阻止切换。认证备份失败时停止操作。

## 每日计划

自动签到页可保存北京时间、当日补执行、重试间隔、每日尝试上限和逐账号开关。当前显示“签到计划暂停”：生产接口与许可未验证，立即签到/批量签到按钮禁用。保存计划不是签到成功；积分暂无更新不能解读为零积分。

客户端需保持托盘运行，退出、睡眠或关机时不会执行。未知结果仅核实，避免重复提交。国际版自动模拟活跃没有加入产品。

## 会话与统计

保留原会话列表、关联、复制、手动增量同步、冲突预览和 Token 统计入口。生产会话复制/同步/恢复暂时拒绝，须先建立与实际 WorkBuddy 版本匹配的完整 schema 验证。不会为满足跨账号显示而改写官方过滤规则。附件、本地文件引用和官方云同步的行为没有兼容性保证。

积分与套餐解析保留，真实积分请求关闭。Token 统计解析本地日志，不上传会话内容；真实日志格式仍未验收。

## 加密备份与恢复

创建加密备份后会解密读回核实，列表显示时间、数量与 UUID。点击“预览恢复”查看范围，确认后才替换 Manager 账号库。恢复前会创建回滚备份；账号库变化、损坏、锁占用或备份失败时取消操作。当前版本不自动修复已损坏的账号索引，请保留原文件。

恢复只影响 Manager 账号资料及凭证，不切换 WorkBuddy 登录，不改官方会话或每日计划。同一 Windows 用户的 DPAPI 环境是解密前提；不要通过公开导出来共享凭证。

## 日志

操作日志显示持久签到任务与最近 100 条本机应用提示。账号切换/删除和备份恢复记录业务结果；会话流程的详细中间记录与备份在原会话流程查看。日志写入是尽力而为，不是防篡改审计服务。凭证相关错误会脱敏，本机明文昵称、标识与路径仍应妥善保管。
# alpha.8 聊天成长计划

在“成长任务”中开启成长计划，选择账号和北京时间，再勾选“自动完成聊天成长任务”并保存。此开关默认关闭；开启后可能消耗模型额度，程序仅补足五次对话任务的剩余进度，每账号每批最多 5 条固定虚构对话，不访问项目文件或调用工具。勾选“自动领取已完成的普通任务奖励”后才会自动领奖。

电脑唤醒且 Manager 运行时处理当天到期批次。关闭聊天开关或取消账号选择会停止后续动作，已发送请求仍需核实。页面出现“待核实”时不要删除操作记录或反复执行；C 的既有 3/5 待核实问题仍保留。该功能只支持已验证的 Windows WorkBuddy 5.8.2/5.8.3 运行时，客户端升级后可能暂停，需完成兼容核验。

## alpha.11 聊天任务补充

新账号先在官方成长计划完成首次 Buddy 入门及活动协议确认，再在 Manager 保存聊天计划。此初始化由账号本人按官方提示完成。每账号每批最多补足 5 条固定虚构对话；达标自动领奖需要保留普通奖励自动领取勾选。

HTTP 成功回执不等于官方任务已接受。遇待核实保留记录，先刷新官方状态；不要删记录或反复点执行。D 本次经过一次明确授权的报名恢复后，真实定时执行、领奖及重启防重复已经通过，预算为 5/5 条；C 的此前旧记录也已在阶段 40 结束核实。默认聊天开关仍关闭，本轮测试结束已恢复用户原计划。
