Windows x64 alpha prerelease. App source: `7965f0afc7ff1e6ace6caf46af598c07f0e3cce0` on `develop/workbuddy-manager` in [workbuddy-switch-app](https://github.com/Jacky0725/workbuddy-switch-app/commit/7965f0afc7ff1e6ace6caf46af598c07f0e3cce0).

Adds validated, same-machine transfers for Buddy-bound local sessions and the observed text/image attachment formats. Buddy bindings retain their shared immutable configuration snapshot; image blobs and original local files are checked for availability and content integrity. Sync previews and interrupted-sync recovery check these resources and stop if they change or disappear.

Validated on WorkBuddy CN 5.8.2: two fictional samples were copied from test account C to B; source records remained unchanged, target ownership and body contents matched, both databases passed integrity checks, and no unfinished operations remained. The user confirmed the copied Buddy conversation opened in the official client and its attachment sample displayed normally. Original account C was restored after the client exited. Core tests: 761 passed; session safety integration tests: 8 passed; server compilation passed. Live Buddy/attachment incremental sync and interrupted-operation recovery have not been performed; those cases were tested in isolated fixtures.

Attachments use shared references within the same Windows user profile; retain the original files. This does not provide portable attachment export. Cloud sessions, official group bindings, cross-variant transfers and unrecognized attachment formats remain blocked. Existing switching, scheduled check-in, points reading and file-history functionality are retained. The installer is unsigned. Verify downloads with SHA256SUMS.txt.
