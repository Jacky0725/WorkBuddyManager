# 每日签到调度

完整设计与测试证据见 [持久每日调度核心](04-daily-scheduler.md)，界面与配置服务见 [统一界面](06-manager-ui.md)。

默认关闭，按北京时间 09:15 计划，可配置当日补执行。业务日期与账号/提供方/区域联合幂等；请求前持久预留，未知结果与重启中断仅核实状态，成功当天不重复。使用文件锁防止多个 host 并发执行。

0.2.0-alpha.1 已保存计划并接入后台心跳；生产适配器关闭，保存启用开关不表示真实签到已经可执行。应用退出、关机或睡眠期间不会执行。Windows 自启动与托盘来自原 Tauri 插件；实际验收范围见测试报告。
