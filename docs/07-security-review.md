# 安全审查与阶段 07 记录

适用版本：0.2.0-alpha.1；检查对象为本工程分支，测试仅使用虚构资料。

## 已实施

| 边界 | 措施与证据 | 限制 |
| --- | --- | --- |
| 账号凭证 | 当前 Windows 用户 DPAPI，索引仅公开字段及随机引用；公开导出不含凭证 | 同 Windows 用户的恶意进程不在此隔离范围；Rust 堆上字符串不保证全部清零 |
| 备份恢复 | DPAPI `.wbm`、固定目录/UUID、32 MiB 限制、目录链接检查、确认、索引 SHA256 预览版本、恢复前备份、准备完整 vault 后原子提交 | 仅 Manager 账号库；损坏的当前索引保留并阻止自动恢复；不承诺跨用户/机器解密 |
| 并发写入 | 账号索引、每日调度跨进程文件锁；认证文件写入另有跨进程锁 | 官方客户端不遵守 Manager 锁；整体切换和官方写入竞争仍需真实环境验证 |
| 浏览器 host | 仅监听 127.0.0.1；所有 API 要求进程内随机会话 cookie；严格 Host/Origin/Fetch-Site；重启使旧 cookie 失效 | 本地 HTTP 会话不是用户密码认证；无 Origin 的本机客户端可以建立会话。桌面安装器不会启动 HTTP host |
| Tauri 参数 | 原生导出对话框在 Rust 打开，参数不再指定导出路径；HTTP 任意路径导出拒绝；备份命令只接受 UUID 与严格恢复结构 | 保留上游手动授权/IDE 命令，不能把本次检查称为第三方渗透审计 |
| 日志 | Rust 通知/错误日志与前端错误输出脱敏：Bearer、Basic、JWT、具名凭证与带空格引号内容 | 无法识别所有无标签秘密；不应向任何错误接口提交 Token；现有本地历史不会自动重写 |
| 网络与自动行为 | 国内签到/积分生产适配器关闭；国际模拟活跃排除；启动不再自动刷新、旅行、轮换或安装 CLI hook；自动更新及 Companion 关闭 | 上游用户主动触发的 OAuth/IDE/轮换能力仍在源码与界面内，尚未真实验收 |
| 资源加载 | Tauri 与 HTTP CSP 仅本地脚本，外部 boot-fallback；禁止 frame/object；安装器自有 WM 标识 | 样式允许内联以兼容现有组件；桌面 IPC 必须以实际界面验证 |
| 更新兼容 | 产品独立 identifier/数据目录；没有使用上游更新源自动升级 | 未建立签名更新服务。仅在备份和版本检查后手工安装候选版本 |

新建凭证/备份目录取消继承，授权当前用户与 SYSTEM。该过程不移除任意既存显式 ACL，不能声称能修复所有用户自定义权限。DPAPI 提供凭证保密。

## 测试和失败记录

完整测试原始结果见 `evidence/phase07-all-tests.log`、`phase07-frontend-tests.log`。新增覆盖加密备份/恢复、失效预览、损坏文件、并发锁、恢复提交失败、认证写入锁、跨站请求与旧 cookie、脱敏。验证结果以测试报告最终记录为准。

首轮旧轮换用例出现日期边界失败，增加注入时钟消除时间漂移；第二轮 CLI fixture 仍硬编码旧存储目录，按新数据目录修正。失败日志保留于 `phase07-first-failed-test.log` 与 `phase07-directory-failed-test.log`。未因测试失败而开放生产门禁。

`source-map-js` 限定为 1.2.2，npm audit 记录为零告警；这是本轮扫描结果，不能推断 Rust、素材或未来依赖没有风险。锁文件同时移除了未使用的 optional peer immer 条目。

打包材料首次源码交叉校验发现许可换行转换和一份忽略的对应源锁文件，已独立修正并保留失败清单。最终候选逐文件哈希、依赖许可/对应源与源码 ZIP、ZIP 与 Git 提交、开发 bundle 均通过离线核验；没有因此将发行源对应或官方兼容性标为已验证。
