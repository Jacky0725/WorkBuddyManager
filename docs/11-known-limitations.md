# 已知限制与完成边界

**当前更新（2026-10-15，alpha.5）**：账号切换、每日计划与固定官方端点的签到/积分核验已有后续记录。国内版 5.8.2 已完成虚构纯文字会话复制/同步、文件历史复制及预览、Buddy/附件复制及客户端查看验证。附件使用同一 Windows 用户下的共享文件引用，原文件不能随意删除或移动；同步和恢复遇到资源变化会停止。Buddy 应用仍受目标账号自身访问条件约束。真实 Buddy/附件增量同步与故障恢复尚未验收；云会话、官方分组、跨档迁移及其他未匹配客户端版本继续关闭。详见 24—26 号记录。下文保留的是较早版本的历史限制，不应视为当前版本全部关闭。

0.2.0-alpha.2 实验安装包已于 2026-10-10 上传到 GitHub Releases；该条目当前未标记为 prerelease。完整任务书尚未全部验收，2026-10-12 的开发源码修复也未包含在已上传安装包中。

Windows 切换账号时需要先关闭官方 WorkBuddy。若官方进程以高于普通用户的权限运行，普通权限的 Manager 可能无法结束它；切换会在写入认证文件前停止。先通过 WorkBuddy 自身退出，必要时在任务管理器确认所有 `WorkBuddy.exe` 已退出，再以普通用户权限启动官方客户端并重试。新开发源码会显示残留 PID；当前 0.2.0-alpha.2 安装候选仍显示通用错误。不要把提升 Manager 权限当作默认解决办法。

2026-10-12 开发源码按独立审查结果恢复签到/积分授权门禁、每日计划暂停状态和官方会话写入门禁。手动签到路由不再对 `run_now()` 使用 `unwrap_err()`。这些修复只在开发源码中；已上传的 0.2.0-alpha.2 安装包未重新打包。签到与积分的凭证用途、官方会话写入兼容性仍需分别验证后才能开放。

当前运行中的 alpha.2 候选包对应旧提交 `1333f84`，其手动签到及积分入口没有后续恢复的授权门禁。用户后来提供显示为官方支持团队、允许相关操作的截图；出处及签到/积分接口合同仍待核验。请勿在该候选包触发签到或积分刷新，也不要把它的调度页面所示 `production_enabled=true` 视为实际生产适配器可用。见 [19 号核对](19-checkin-credits-verification-decision.md)。
